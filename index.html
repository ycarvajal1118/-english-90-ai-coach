Configuración

La web estática no puede ocultar una clave secreta. Para conectar una IA de forma segura se necesita un backend con la clave guardada en el servidor. Si el endpoint está vacío, se usa el motor local sin tokens de API. En conversación, la IA solo se consulta para respuestas largas sin errores locales conocidos; en escritura, la revisión de IA es manual y opcional.

Tus respuestas y progreso se guardan localmente en este navegador. Borrar los datos de Safari puede eliminarlos.
